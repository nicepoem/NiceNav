## 熟悉 NiceNav 项目（前端开发专家视角）

定位：本地优先的个人导航起始页。纯前端 Vue 3 + TS + Vite，无后端依赖（数据存 IndexedDB）。

技术栈：Vue 3.5 + Pinia 3 + vue-router 4 + Element Plus 2.9 + @iconify/vue + dexie 4 + zod 3 + sortablejs + Sass + Vite 6。

关键架构：
- 积木式模块布局：`src/layouts/BlockShell.vue` 提供 9 个具名插槽（topNav/topFull/leftSidebar/mainTop/main/mainBottom/rightSidebar/bottomFull/footer），`src/modules/` 通过 `AppModule` 向插槽填组件。新增功能只需实现 slot 组件 + 在 `registry.ts` 注册。
- 状态层：`src/stores/nav.ts`（Pinia）持有 categories/sites/settings，封装 CRUD、排序、导入导出、跨标签页同步（BroadcastChannel）。
- 存储抽象：`src/core/storage/` 定义 NavStorage 接口，IndexedDbStorage（dexie）为主，IndexedDB 不可用时降级 MemoryStorage。
- 数据模型：`Category`（最多两级）/ `Site` / `AppSettings`，含主题、搜索引擎、favicon/元数据第三方开关、浮动工具栏、顶栏自定义菜单。
- 双构建目标：`createWebHistory`（web）vs `createWebHashHistory`（extension，VITE_APP_TARGET=extension）；`pnpm build:extension` 产出 Chrome/Edge 新标签页扩展（manifest v3，chrome_url_overrides.newtab，background service worker 代抓元数据/探测图标）。
- 元数据抓取：`server/meta-api.mjs` 提供 `/api/page-meta`、`/api/icon-probe`（同源规避 CORS），开发与 `pnpm start` 共用；扩展走 background.ts 抓取。

工作区状态：main 分支，当前有 12 个已修改文件 + vite.shared.ts 未跟踪（改动涉及 package.json、SiteCard、SiteFormDialog、core/types、extension/background、page-meta、site-icon、vite 配置等），尚未提交。node_modules 已安装，项目可直接 `pnpm dev` 运行。

## UI 视觉重构（解决"网址多→太白太生硬"）
问题根因：页面为"灰底(#f3f4f6)→纯白分类面板(#fff)→灰白卡片(#f5f6f8)"的平面结构，缺层次与色彩。
改动（集中在令牌层 + 2 个组件，已通过 vue-tsc 与 vite build）：
- `src/styles/main.scss`：新增环境光变量（珊瑚/天空蓝/紫/薄荷）；`body` 叠加固定在视口的低饱和径向渐变光斑（明暗双主题各一套色）；阴影全部改为柔和大弥散暖中性投影；面板/侧栏/卡片/分类块改为半透磨砂白（暗色为半透暗）；新增 `--nn-card-border`/`--nn-cat-block-shadow`/`--nn-cat-block-border`/`--nn-hairline`/`--nn-hero-engine-bg`/`--nn-field-shadow`（保留输入框内凹语义，不被卡片外投影带偏）。
- `src/components/site/SiteCard.vue`：卡片加发丝描边、圆角 10→12、悬停轻抬 2px + 柔和阴影 + 主色描边。
- `src/components/site/CategorySection.vue`：`.cat-block` 应用磨砂面板阴影与描边。
效果：环境光从面板/卡片/间隙透出，形成"环境光→磨砂面板→浮起卡片"层次，消除白墙与生硬感；暗色主题同步软化。
注意：`pnpm build` 因 `pnpm-workspace.yaml` 缺 `packages` 字段报错（工作区配置问题，与改动无关）；改用 `node_modules/.bin/vite build` 与 `node_modules/.bin/vue-tsc -b` 验证。开发预览：`node_modules/.bin/vite --host`（默认 5173）。

## UI 风格二次优化（参考 dsxdh.com / OneNav 主题）
分析 dsxdh.com 源码（WordPress + OneNav 主题 main.min.css）：主色 `--theme-color:#f1404b`（与 NiceNav `--nn-primary` 完全一致），悬停玫红 `#d12768`；招牌手法=主题色→玫红对角渐变用于强调元素、分类标题左侧主题色竖条、网址图标浅色圆角容器、顶栏半透磨砂白 `rgba(245,245,245,.75)`、统一 12px 圆角、柔和单层阴影 `rgba(0,0,0,.1)`、页面中性浅灰 `#f2f4f7`（克制不花哨）。
本轮在既有"磨砂+环境光"层次基础上融合 OneNav 识别特征（已通过 vite build）：
- `src/styles/main.scss`：新增 `--nn-primary-grad`（红→玫红 135° 渐变，明暗双主题；暗底玫红提亮为 #ec5a86）与 `--nn-primary-grad-soft`；**收敛上一轮的多彩环境光**——`body` 背景由四色光斑(0.12-0.16)改为两色极淡光晕(0.08-0.10)，`--nn-page-bg` 由 #eef1f7 调为 #f2f4f7，回归 dsxdh 式中性克制底；新增全局 `.el-button--primary:not(.is-plain)` 套用渐变 + 柔投影。
- `src/components/layout/AppHeader.vue`：`.cta-add`、`.sort-toggle.is-active` 背景由纯主色改 `--nn-primary-grad` 并加柔投影。
- `src/components/site/CategorySection.vue`：`.cat-block__heading` 左侧加 4px 主题色渐变竖条（OneNav 招牌）。
- `src/components/site/SiteCard.vue`：卡片悬停时 `.url-card__icon` 背景切 `--nn-primary-grad` + 图标变白，强化品牌交互质感。
预览：`http://localhost:5173/`（vite dev 已运行，刷新即见最新样式）。

## UI 风格三次微调（用户反馈：链接去掉图标变色 + 所有页面去除全局阴影）
用户看截图后要求：① 链接卡片悬停时图标不再变色；② 全站去除投影（global shadows）。
改动（已通过 vite build）：
- `src/styles/main.scss`：在 `:root` 与 `html.dark` 末尾各加一段"阴影归零"重置，把 `--nn-shadow/--nn-shadow-hover/--nn-card-inset/--nn-card-inset-hover/--nn-elevated-shadow(-hover)/--nn-chrome-shadow/--nn-sidebar-shadow/--nn-panel-shadow/--nn-header-shadow/--nn-cat-block-shadow/--nn-glass-tile-shadow` 全部置 `none`（令牌级一次性去除，影响全站卡片/面板/侧栏/顶栏/弹窗/浮窗）。
- 同步删除未走令牌的硬编码装饰投影：`.nn-btn--primary`、`.el-button--primary` 的柔投影；`.el-message-box` 0 16px 48px 投影；`.nn-sidebar-popup` 0 4px 14px 投影；`.nn-site-tip` 与侧栏 tooltip 的 `var(--el-box-shadow-light)`；`AppHeader .cta-add` 主色投影；`FloatingDock .is-active` 主色辉光；`ImportDialog` active 标签 0 1px 4px 投影。
- `src/components/site/SiteCard.vue`：移除悬停时 `.url-card__icon { background: var(--nn-primary-grad); color:#fff }` 的图标变色块（保留标题→主色、卡片轻抬 2px 与发丝描边的悬停反馈）。
保留项：body 环境光渐变（属背景非阴影，维持"不刺眼"的柔底）；表单 `--nn-field-shadow` 内凹输入；各类 `:focus`/`:focus-visible` 主色描边（功能性，非装饰投影）。
效果：页面回归干净平面观感，卡片/面板仅以发丝描边与半透底色区分层次；保留 OneNav 式主题色渐变（按钮/标题竖条）作为品牌识别。

## 第 6 轮微调（视觉减法收尾）
用户连续指令的视觉减法序列：去图标变色 → 去全局阴影 → 去分类标题红竖线 → 「整体背景变白色」(`--nn-page-bg:#ffffff` 并去掉 body 环境光) → 「body 不要白色、去除背景」(`--nn-page-bg:transparent`) → 最终选「柔和浅灰/暖灰底」(`--nn-page-bg:#f2f4f7`)。
当前视觉定稿（明/暗双主题）：
- 整页底：明 `#f2f4f7`（中性柔和浅灰，呼应 dsxdh/OneNav），暗 `#11131a` 深底。
- 阴影：全站归零（令牌 none + 硬编码装饰投影已删）。
- 边框/描边：卡片 `border:none`；分类面板/侧栏/顶栏发丝描边透明；`--nn-hairline` 透明。
- 链接卡片：按 id 哈希 `hsl(hue,58%,94%)` 淡彩底，悬停仅标题变主色 + 轻抬 2px，无图标变色、无边框。
- 保留：主题色红→玫红渐变（主按钮/强调）、彩色玻璃背景（仅顶部 hero 带，非整页）、表单内凹与焦点描边。
- body 已无 `background-image`（无环境光/渐变层）。
预览：`http://localhost:5173/`（vite dev 运行中，刷新即见）。构建用 `node_modules/.bin/vite build`，类型检查 `node_modules/.bin/vue-tsc -b`。
